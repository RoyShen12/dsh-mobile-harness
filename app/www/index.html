打开「DSH Mobile Harness」的无障碍服务后，电脑上的 agent 才能读屏和点按；支付、银行、系统设置一律拒绝代操作。默认关闭，随时可以关掉。

「相机扫码」会打开取景框，把电脑上的二维码放进去就自动识别，不用按快门。二维码只含地址（截图外发也进不来密码）：识别后会用这台手机记住的密码自动登录，第一次仍需手填一次密码。
密码在本机校验，通过后由电脑弹出配对码，两边数字一致才算登录成功。
HTTPS 入口必须使用 Android 系统信任的证书；证书错误或自签证书会被拒绝。局域网入口可使用私有 IPv4 的 HTTP 地址。
